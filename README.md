# Flask + Bootstrap Starter

Quick starter for a Flask website using the bundled Bootstrap files in this repository.

Run locally (PowerShell):

```
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000/ in your browser.

Notes:
- The project includes a local Bootstrap distribution in `bootstrap-4.4.1-dist/` and the app exposes those files at the `/bootstrap/...` URL prefix.
- The main template is `templates/index.html`.
